# Government Tourism Portal

This repository contains the frontend container:

- frontend_web_app: React + Vite + Tailwind CSS app with Agent/Admin flows, registration & renewal, OTP simulation, and admin dashboard with map.

See frontend_web_app/README.md for setup instructions.

Environment quick start:
- Copy frontend_web_app/.env.example to frontend_web_app/.env
- Ensure:
  - PORT=3000
  - HOST=0.0.0.0
  - VITE_API_BASE_URL=http://localhost:3001
