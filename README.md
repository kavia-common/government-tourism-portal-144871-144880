# Government Tourism Portal

This repository contains a complete, fresh React frontend for the Government Tourism Portal.

- Ocean Professional theme (primary #2563EB, secondary #F59E0B, error #EF4444)
- Agent and Admin login
- Tourist Registration and Renewal with OTP flow and simulated Blockchain ID
- Admin Dashboard (map placeholder, status cards, alerts, incident list)
- Tailwind CSS (v4) + React Router
- Environment-driven API base URL via REACT_APP_API_BASE_URL

See frontend_web_app/README.md for detailed instructions.
