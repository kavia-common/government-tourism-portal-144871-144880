# government-tourism-portal-144871-144880

This repository contains the Government Tourism Portal frontend web app (React + Tailwind CSS) located under `frontend_web_app/`.

How to run the frontend_web_app:
1. cd frontend_web_app
2. npm install
3. npm run dev
4. Open http://localhost:3000

Features implemented:
- Agent/Admin login (simulated)
- Tourist Registration and Renewal with OTP simulation (email and phone)
- Dynamic form fields by nationality (Domestic vs Foreign)
- Simulated blockchain-based Digital Tourist ID (Polygon) issuance
- Admin Dashboard with Leaflet map, geofence circle, incident markers
- Emergency alerts panel with Respond and Track actions
- Responsive, modern government-themed UI

Environment:
- No external env variables required for the demo. Ready to connect to a future backend via services layer.
